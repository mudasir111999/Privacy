Autofill Vault is a lightweight browser extension that stores your login entries locally and autofills login forms in one click.

The extension gives you a clean vault panel where you can save, organise, and instantly fill credentials on supported sites. It is built for people who sign in to the same handful of portals every day and do not want to rely on a heavyweight password manager.

Key Features

• Secure local-only storage
All entries are saved in your browser via chrome.storage.local. Usernames, passwords, notes, mobile numbers, CNICs, and any IRIS-specific fields stay on your device and are never uploaded to our servers.

• One-click autofill
Pick an entry from the panel and the extension fills the current page's login form automatically.

• IRIS (FBR) portal mode
On iris.fbr.gov.pk, the panel switches to an IRIS-optimised layout that handles CNIC, mobile number, and email-based autofill for that site.

• Show All Websites toggle
Toggle "Show All Websites" in the profile view to see every saved entry across every domain, and to reveal the Site Domain field when adding new records.

• Full account management
Add, edit, and delete entries from the popup. The Site Domain is editable while adding, and locked once saved so entries stay tied to the right site.

• Import and export
Bulk-import entries from a CSV or Excel file, and export your vault at any time for backup or transfer.

• Site-specific filtering and search
By default, the list only shows entries saved for the current site. Search by label, username, or notes to jump to any record in seconds.

• Free, PRO, and MAX tiers
The free tier supports up to 4 saved entries. PRO (time-limited) and MAX (lifetime) licenses unlock unlimited entries.

How It Works

1. Install the extension, add to toolbar and open the vault panel.
2. Add your login entries to the vault.
3. Visit a supported login page.
4. Click the extension icon and select the entry you want to use.
5. The extension fills the login form automatically and hit the login.

Privacy and Data Usage

Autofill Vault is designed with privacy in mind.

• All saved entries — including usernames, passwords, notes, mobile numbers, CNICs, emails, and email passwords — are stored locally on your device only.
• The extension does not collect browsing history, keystrokes, or form content.
• The extension does not sell or share personal data.
• The only data that ever leaves your browser is the license-verification request, which contains your license key and a randomly generated install ID — nothing else.
• The server response only reports license validity, plan (PRO/MAX), and expiry date (if any).

Permissions Usage

• storage – used to save your entries, install ID, license key, and UI preferences locally.
• activeTab – used to interact with the current webpage when autofilling login forms.
• scripting – used to inject the autofill functionality into the current page.

Support

Need help with activation, a license reset, or moving your license to a new computer? Use the "For Inquiries" Contact Us button in the extension's profile view. Please include your license key and a short description of the issue so we can respond faster.
